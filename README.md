Attendance Ledger

Check your college attendance percentage with a simple calendar based on the AKTU academic calendar





Note: This app is made only for the AKTU academic calendar (B.Tech 1st Year, ODD Semester 2026-27) 



The semester dates and holidays are set for that calendar so it will not match the calendar of any other university



What you can do

Enter your name and open your semester calendar

Tap a day to mark it as a full day present (all 8 lectures). Tap it again to un-mark it

Press and hold a day to see its 8 lectures all selected. Untick the ones you missed and press Save

See your attendance percentage classes conducted classes attended and classes missed updated instantly

Set your own target (75% by default) and see how many lectures you can still miss, or how many you need to attend to reach it

Come back any time to edit old days or mark new ones

Holidays Sundays and Saturdays

Sundays and holidays are locked Tap one to see the reason (for example, Gandhi Jayanti)

On a Saturday the app first asks whether it is a working day for you If you say yes you can mark it like a normal day and it counts in your percentage If you say no it stays off and does not count

Days before the semester starts and days that have not happened yet cannot be marked

How the percentage is calculated

Each class day has 8 lectures

Classes attended = the lectures you marked

Classes missed = classes conducted − classes attended

Attendance % = classes attended ÷ classes conducted × 100




A class day you have not marked counts as absent so remember to mark every day you attended


How to run

Keep index.html, style.css and script.js together in one folder

Open index.html in a web browser



You need an internet connection, because the app loads its SQL library and fonts from the web. There is nothing to install.
